Tutorial Membuat Game Pass

1

Buka Roblox Create

Kunjungi create.roblox.com dan login ke akun Anda.

2

Pilih Game Anda

Pilih game yang ingin Anda tambahkan Game Pass, lalu buka bagian "Associated Items" → "Game Passes" → "Create Pass".

3

Buat Game Pass

Upload gambar, isi nama & deskripsi yang menarik untuk Game Pass Anda.

4

Atur Harga

Buka Configure → Sales → aktifkan "Item for Sale" → isi harga sesuai kalkulator → matikan "Regional Pricing" → Save.
